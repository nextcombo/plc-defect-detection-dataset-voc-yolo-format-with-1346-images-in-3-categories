# PLC Defect Detection Dataset VOC+YOLO format with 1346 images in 3 categories

Dataset format: Pascal VOC format + YOLO format (txt file without split path, only containing jpg images and corresponding VOC format xml files and yolo format txt files)

Number of images (number of jpg files): 1346

Number of annotations (number of xml files): 1346

Number of annotations (number of txt files): 1346

Label category count: 3

Label category names (note that the order of yolo format categories does not correspond to this, but is based on the labels folder's classes.txt): ["insufficient_solder", "missing_component", "soldering_shorted"]

Number of boxes labeled in each category:

Insufficient solder Frames = 3287

missing_component Frames = 836

Soldering shorted frame count = 1960

Total frame count: 6083

Using labelImg:

Annotation rules: Draw a rectangle around the category.

Important Notice: No

Special : This dataset does not guarantee the accuracy or precision of the trained models or weight files. The dataset is provided with accurate and reasonable annotations only.
